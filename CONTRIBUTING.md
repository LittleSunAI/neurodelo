# Участие в NEURODELO

NEURODELO находится на стадии локального прототипа. Перед изменениями ознакомьтесь с README и docs/KNOWN_LIMITATIONS.md.

1. Создайте issue с описанием проблемы или предлагаемого изменения.
2. Создайте fork и отдельную ветку для изменения.
3. Установите зависимости командой `npm ci` (в Windows PowerShell можно использовать `npm.cmd ci`).
4. Выполните `npm run build` и `npm run test:release`. Для изменений серверного поведения также выполните `npm run test:http`, `npm run test:prebackend-runtime` и `npm run test:persistence:runtime` после сборки.
5. Откройте pull request с описанием поведения и результатами проверки.

Не добавляйте ключи, `.env`, `.data/`, пользовательские данные, зависимости или результаты сборки. Уязвимости и секреты не публикуйте в открытых issues; см. SECURITY.md.

Предоставляя изменения для включения в проект, вы соглашаетесь распространять их по Apache License 2.0 в соответствии с разделом 5 LICENSE. Указывайте происхождение стороннего кода и сохраняйте необходимые уведомления.
