# NEURODELO

**NEURODELO** — открываемая для сообщества площадка, которая помогает людям находить проекты с доступным исходным кодом, вести страницы проектов и новости, распределять задачи, общаться и отмечать вклад участников. GitHub остаётся средой хранения и совместной работы над кодом; NEURODELO делает работу с проектами понятнее для широкой аудитории.

**Текущий статус: локальный прототип 0.23.0, не готовый к публичному развёртыванию.** Репозиторий содержит исходный код, документацию и испытательные механизмы, но PostgreSQL, Redis, хранилище файлов и проект шифрования пока не соединены в законченную промышленную систему. Часть внешних интеграций работает в демонстрационном режиме.

## Возможности

- Профили, регистрация, настройки приватности и уведомления.
- Каталог проектов; страницы, задачи, этапы, новости и выпуски.
- Сообщество: форум, переписка, поддержка команд, модерация.
- Учёт вкладов, достижения, наставничество и игровые элементы сообщества.
- Подготовленные адаптеры GitHub и fal.ai, а также серверные ограничения запросов.
- Локальные защищённые вложения, сохранение состояния, экспорт/импорт и очередь заданий.
- Схема PostgreSQL из 78 таблиц и 7 миграций, спецификация API.

## Локальный запуск

Для проверки публикации используются **Node.js 24 и npm 11**. На Windows можно дважды щёлкнуть `START_WINDOWS.bat`. В терминале:

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000`. Демонстрационный вход с известным паролем предназначен **только для местной разработки**; на обычном производственном сервере автосоздание таких аккаунтов отключено. Не копируйте локальные данные `.data/` на публичный сервер.

Проверка компонентов:

```bash
npm run lint
npm run typecheck
npm run test:database
npm run test:openapi
npm run test:final
```

Тестирование HTTP с демонстрационным администратором выполняется **только в изолированном временном каталоге** командой `npm run test:http` после сборки. Нельзя задавать `NEURODELO_TEST_DEMO_USERS=true` на реальном сервере.
