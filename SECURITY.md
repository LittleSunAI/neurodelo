# Security Policy

## Supported status

Этот репозиторий пока является локальным прототипом и не предназначен для хранения реальных секретов или персональных данных в интернете.

## Reporting a vulnerability

Не публикуйте секреты, токены, пароли или персональные данные в открытых issues. Перед публичным запуском необходимо назначить отдельный security contact и закрытый канал для сообщений об уязвимостях.

## Local data

Каталоги `.data/` и `backups/` содержат локальные аккаунты, сессии и события. Они исключены из Git и не должны передаваться третьим лицам.
