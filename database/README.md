# База данных NeuroDelo Platform

База пока **не запускается**. Папка содержит проектную схему PostgreSQL 18+, миграции, политики доступа и детерминированные тестовые данные для перехода с локальных файловых адаптеров.

## Состав

- `migrations/0001_core_identity.sql` — аккаунты, сессии, профиль, навыки и настройки.
- `migrations/0002_projects_git.sql` — проекты, задачи, участники и Git-снимки.
- `migrations/0003_contributions_recognition_game.sql` — вклады, XP, благодарности, герой и игра.
- `migrations/0004_community_moderation_notifications.sql` — форум, чаты, жалобы, модерация и уведомления.
- `migrations/0005_rls_policies.sql` — Row-Level Security и функции проверки членства.
- `migrations/0006_reference_data.sql` — профессии, категории, игровые справочники и feature flags.
- `migrations/0007_prebackend_storage_jobs.sql` — файлы, экспорт данных, фоновые задания и события внешних провайдеров.
- `seeds/development.sql` — SQL seed для будущего локального PostgreSQL.
- `seeds/development.json` — машиночитаемый seed для контрактных тестов.
- `schema-manifest.json` — список таблиц, порядок миграций, безопасность и retention.

## Основные решения

- UUID создаются через `pgcrypto`.
- Email и публичные slug используют `citext`.
- Время хранится в `timestamptz` и трактуется как UTC.
- Денежного кошелька и escrow в схеме нет.
- XP-журнал неизменяемый: ошибка исправляется отдельной обратной операцией.
- Git-токены обозначены как `*_ciphertext`; шифрование выполняется серверным KMS/secret layer.
- Публичные проекты, публичные профили и принятые вклады доступны на чтение.
- Личные настройки, сессии, сообщения и изображения защищаются RLS.

## Как будет применяться позже

Будущий migration runner должен:

1. создать отдельную базу;
2. открыть транзакцию для каждой миграции;
3. вычислить checksum файла;
4. проверить `app.schema_migrations`;
5. применить миграции строго по порядку;
6. установить роль приложения без прав владельца схемы;
7. перед каждым запросом выставлять `SET LOCAL app.current_account_id = '<uuid>'`.

Сейчас корректность проверяется командой:

```bash
npm run test:database
```
