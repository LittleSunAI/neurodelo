# Хранение и удаление данных

Это техническая заготовка, а не юридическая политика.

- Сессии удаляются после истечения или отзыва.
- Токены восстановления и подтверждения удаляются после использования или срока действия.
- История входов хранится ограниченный период для безопасности.
- Пользовательские сообщения сначала получают `deleted_at`; физическое удаление выполняется отдельной политикой retention.
- Удаление аккаунта сначала блокирует вход и скрывает профиль.
- После установленного срока персональные поля анонимизируются.
- Вклады, release credits, XP ledger и модерационный аудит сохраняют обезличенную техническую историю.
- Git access tokens удаляются сразу при отключении интеграции.
- Загруженные изображения удаляются из object storage и затем из таблицы метаданных.
- Резервные копии очищаются по отдельному жизненному циклу.
