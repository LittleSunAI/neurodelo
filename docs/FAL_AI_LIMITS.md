# Защита fal.ai

fal.ai вызывается только серверным маршрутом `POST /api/v1/hero-images/generate`. Ключ не передаётся браузеру.

## Ограничения по умолчанию

```env
FAL_MAX_GENERATIONS_PER_DAY=5
FAL_MAX_ESTIMATED_DAILY_USD=1.00
FAL_ESTIMATED_COST_PER_GENERATION_USD=0.08
FAL_MAX_REQUESTS_PER_MINUTE=2
FAL_REQUEST_TIMEOUT_MS=45000
```

Сервер блокирует запрос, если достигнут лимит числа генераций или приблизительный дневной бюджет. В интерфейсе показываются использованные генерации и расход.

## Дополнительная защита

- требуется подписанная сессия;
- проверяется Origin;
- обязателен `Idempotency-Key`;
- одинаковый выполняющийся запрос блокируется;
- готовый результат одного ключа возвращается повторно без новой траты;
- модель выбирается только из серверного allowlist;
- параметры и длина prompt валидируются;
- действует локальный список запрещённых запросов;
- запрос имеет timeout;
- URL изображения принимается только по HTTPS с разрешённых доменов;
- при ошибке резервация квоты откатывается.

## Ограничение текущей версии

Счётчик хранится в памяти процесса. Для нескольких серверов нужен Redis с атомарной операцией. Оценка стоимости приблизительная; production-версия должна сверять фактические расходы provider и сохранять их в ledger.
