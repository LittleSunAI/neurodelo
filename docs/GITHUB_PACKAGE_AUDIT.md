# Проверка комплекта для GitHub

## Источник и границы

Основа: исходный архив `RUN_GAME_FALLBACK_TESTS_WINDOWS.zip`, содержащий локальный прототип NEURODELO 0.23.0. Включена **площадка NEURODELO**, а не самостоятельные игры. Из корня удалены вложенные ZIP, устаревший манифест прошлой сборки и избыточные файлы запуска отдельных тестов Windows. Нужные испытания остаются доступными через `npm run ...`.

## Включено

Исходный код `app/`, `components/`, `lib/`, `services/`, `integrations/`, `data/`, `types/`; база `database/`; API `api/`; тесты `tests/`; документация `docs/`; локальная инфраструктура `infrastructure/`; необходимые конфигурации и файл фиксации версий npm. В `docs/encryption-design/` добавлены четыре канонических документа целевой системы шифрования.

## Исключено

Все вложенные ZIP, отдельный комплект `BEGET_GAME_CURRENT_PLATFORM_PACK_AUDITED...` и игровые установочные документы, старые контрольные снимки упаковки. Не включены пользовательские `.data/`, реальные ключи `.env*`, папки зависимостей и сборки. Остались игровые элементы, **принадлежащие самому сайту** (персонажи, достижения) — это часть NEURODELO, а не отдельная игра.

## Точечные изменения безопасности и совместимости

1. Предусмотрен запрет автоматического создания известного демонстрационного администратора при обычном производственном запуске. Прежние локальные тесты сохраняют возможность работать с изолированным временным каталогом и явным флагом для тестов.
2. Для PostgreSQL 18 исправлен путь хранения данных именованного тома контейнера.
3. Расширен `.gitignore`, добавлены инструкции по лицензии и публикации.

## Ограничения аудита

- Точный правовой статус всех ресурсов и исходников не подтверждён: до свободной лицензии необходима проверка авторских прав и зависимостей.
- Статические проверки не доказывают безопасность при публичной работе.
- Наличие схемы БД и контейнеров не означает подключения PostgreSQL к сайту.
- Реальная система шифрования всё ещё только документирована, не внедрена.
- Не гарантируется работоспособность любых интеграций без ключей, настройки и договорных условий поставщиков.
