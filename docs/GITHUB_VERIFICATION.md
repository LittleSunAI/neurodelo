## Дополнительные замечания перед публикацией

1. **Нет файла `LICENSE`.** Это осознанно: владелец пока не подтвердил выбор свободной лицензии. До открытого распространения надо выбрать лицензию, проверить авторство кода и права на вложенные материалы.
2. Из исходного проекта исключены материалы отдельной игры и вложенные архивы. Игровые механики самого NEURODELO сохранены.
3. Встроенные тестовые учётные записи с известными паролями оставлены для локального режима, но при обычном производственном запуске их создание теперь отключено. Нельзя включать тестовый флаг на реальном сервере.
4. Сайт пока не готов к размещению в интернете с реальными людьми: серверная база, надёжные загрузки, почтовая доставка, проект шифрования и другие внешние службы требуют реализации и проверки.
5. Ранее созданные локальные пароли, ключи, пользовательские данные и история Git **не включались** в архив. Если впоследствии их добавят, нужно отдельно проверять репозиторий и историю коммитов.

## Итог

Комплект можно использовать как **исходный код проекта для GitHub** после выбора лицензии и проверки на актуальность. Его нельзя считать независимо проверенной производственной сборкой или безопасным публичным сайтом.
