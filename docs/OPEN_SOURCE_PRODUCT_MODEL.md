# Продуктовая модель: open-source ядро

## Основной объект платформы

Главный объект — публичный open-source проект. У него есть:

- описание и цель;
- открытая лицензия;
- публичный репозиторий;
- roadmap;
- команда мейнтейнеров;
- CONTRIBUTING.md;
- открытые задачи;
- история принятых вкладов;
- правила оценки XP и навыков.

## Основные роли

### Контрибьютор

Находит проект, берёт подходящую задачу, вносит проверяемый вклад и развивает профиль.

### Автор проекта / мейнтейнер

Публикует проект, поддерживает roadmap, формулирует задачи, проводит ревью и принимает решения по основной ветке.

### Наставник

Помогает новичкам, проверяет учебные patch, объясняет комментарии ревью и подтверждает развитие навыков.

## Оценка вклада

XP не должен зависеть от количества строк или коммитов. Учитываются:

- сложность задачи;
- завершённость результата;
- качество и понятность решения;
- тесты;
- документация;
- соблюдение правил проекта;
- коммуникация при ревью;
- решение мейнтейнера или подтверждённого наставника.

## Частные запросы

Раздел запросов является второстепенной информационной доской. Платформа:

- не принимает оплату;
- не замораживает деньги;
- не гарантирует исполнение;
- не является стороной договора;
- не определяет юридическую ответственность;
- только предоставляет публикацию, связь и модерацию запрещённого содержания.
