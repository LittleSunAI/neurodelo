# Проверка данных после полного перезапуска сервера

Проверка выполнялась на production-сборке:

1. Сервер запущен с пустым каталогом данных.
2. Зарегистрирован новый пользователь.
3. Через `/api/v1/local-state` сохранено пользовательское состояние.
4. Node.js процесс полностью остановлен.
5. Сервер запущен повторно с тем же каталогом данных.
6. Старая подписанная cookie осталась действующей.
7. Список активных сессий восстановился.
8. Сохранённый PlatformState вернулся без изменений.

Результат: аккаунты, сессия и состояние пережили полный перезапуск процесса.
