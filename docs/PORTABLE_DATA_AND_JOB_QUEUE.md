# Переносимые данные и локальная очередь

## Экспорт и импорт

`GET /api/v1/portable-data` создаёт переносимый пакет:

- формат `neurodelo-portable-data`;
- версия формата;
- дата экспорта;
- версия выпуска;
- полный `PlatformState`;
- SHA-256 контрольная сумма.

`POST /api/v1/portable-data` сначала поддерживает `dryRun`, проверяет структуру и контрольную сумму, а затем по явному подтверждению заменяет состояние текущего аккаунта.

В настройках аккаунта доступны экспорт и импорт JSON. При недоступности серверного маршрута экспорт умеет использовать резервный клиентский формат, однако импорт требует серверной проверки.

## Локальная очередь задач

Очередь хранится через `PersistentStore` и поддерживает:

- `queued`, `processing`, `completed`, `failed`, `cancelled`;
- задержку выполнения;
- блокировку задания worker-id;
- повторные попытки;
- deduplication key;
- ограничение размера payload;
- очистку старых завершённых заданий.

Очередь предназначена для локальной разработки. В production интерфейс заменяется Redis/BullMQ, а бизнес-код не должен зависеть от файлового драйвера.
