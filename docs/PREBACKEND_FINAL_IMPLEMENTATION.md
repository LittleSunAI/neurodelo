# Prebackend Final — выполненные локальные возможности

Версия: 0.23.0

## Добавлено после Persistent Storage Foundation

1. Безопасное локальное файловое хранилище.
2. Карантин и review файлов.
3. Настоящие защищённые вложения чата.
4. Переносимый экспорт/импорт состояния с контрольной суммой.
5. Предварительная проверка импорта до замены данных.
6. Долговечная локальная очередь фоновых задач.
7. Retry, lock и deduplication фоновых задач.
8. Миграция PostgreSQL `0007_prebackend_storage_jobs.sql`.
9. Таблицы файлов, экспортов, задач и событий провайдеров.
10. OpenAPI-модули Files, Data portability и Jobs.
11. Расширенный runtime-тест двух аккаунтов и object-level доступа.
12. Threat-model тест опасных URL, ролей и вредоносных файлов.
13. Команда локального обслуживания `npm run data:cleanup`.
14. Стабилизация Next.js production-сборки одним build-worker.
