# Техническая основа прототипа

- Next.js App Router, React и TypeScript.
- Основная дизайн-система в `app/globals.css`.
- Fallback/API переключатель в `lib/fallback-config.ts`.
- Единый gateway в `services/platform-gateway.ts`.
- Состояние и действия в `components/platform-provider.tsx`.
- Публичная продуктовая модель строится вокруг open-source репозиториев, задач и вкладов.

Текущий прототип не подключён к GitHub/GitLab и не должен получать реальные токены. Настоящая интеграция должна использовать отдельное приложение с минимальными правами и явным выбором репозитория пользователем.
