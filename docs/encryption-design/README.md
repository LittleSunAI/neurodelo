# Архитектура шифрования — целевое проектирование

В этой папке сохранены четыре канонических текстовых документа из предоставленного разработчиком проекта. Это **спецификация будущей системы**, а не работающий модуль NEURODELO.

Цель: отдельно шифровать пользовательские сведения, хранить ключевой материал отдельно от основной базы, поддерживать разделение главного секрета «2 из 3», независимые резервные копии и восстановление. При размещении всего на одном VPS злоумышленник, получивший полный контроль над ним, может обойти часть изоляции. Перед запуском нужны реализация, внешняя проверка, отработка восстановления и настройка безопасного управления ключами.

Публикация спецификации не означает, что нужно публиковать реальные части секретов, пароли восстановления, действующие ключи или зашифрованные резервные копии.
